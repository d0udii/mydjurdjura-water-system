## 📦 **ORDER MANAGEMENT GUIDE**

### **🆕 Creating Orders**

#### **Step-by-Step Order Creation**
1. **Navigate** to Orders page
2. **Click** "Create New Order"
3. **Select Client** from dropdown
4. **Enter Quantities**:
   - 5.5L bottles (pallets)
   - 1.5L bottles (pallets)
5. **Choose Truck Type**:
   - Factory truck (with transport cost)
   - Client's own truck (no transport cost)
6. **Add Notes** (optional)
7. **Click** "Create Order"

#### **Order Details**
- **Region**: Auto-assigned from client
- **Pricing**: Automatically calculated
- **Delivery Date**: Auto-set to 2 days from creation
- **Status**: Set to "Pending"

### **💰 Payment Tracking**

#### **Payment Status Types**
- **Unpaid**: No payment received
- **Partial**: Partial payment received
- **Paid**: Full payment received

#### **Payment Management**
1. **View Order** → Select order
2. **Payment Tab** → View payment details
3. **Update Payment** → Record payment
4. **Track Progress** → Monitor payment status

### **📊 Order Tracking**

#### **Order Status Flow**
1. **Pending** → Order created, awaiting processing
2. **Processing** → Order being prepared
3. **In Transit** → Order en route to client
4. **Delivered** → Order successfully delivered
5. **Cancelled** → Order cancelled

#### **Tracking Features**
- Real-time status updates
- Delivery progress tracking
- Payment status monitoring
- Issue resolution tracking
